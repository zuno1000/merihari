# merihari(メリハリ)

ワンタップの実績記録 × きょうの内訳と目安 × カレンダー(手帳の升目) × 日次レポート × ふり返り(日記) × お金 の個人用 PWA。
朝に自分で置いた予定(枠線だけ)と実際を比べ、夜に「どんな一日だったか」を責めない言葉と図で返す。
サーバー無し・無料。GitHub Pages で配信。データは端末(localStorage)と、端末側で暗号化して置く Google Drive(appDataFolder)だけ。

- 公開URL: https://zuno1000.github.io/merihari/
- 仕様書(正): [docs/仕様書.html](docs/仕様書.html)(要件 ID F1-1 … F12-5)

## 画面(5 タブ+設定)
- ホーム: きょうの内訳(円・カテゴリ別の棒)だけ / 未記録の「何をしていた?」/ 左上のカレンダーで過去の日へ / 右上の歯車が設定(未同期や控えの書き出しがあると赤い点)
- カレンダー: 上に手帳の升目(週の帯 / 月の升目)、下に実績 1 レーン。未記録の「この時間は?」、カレンダーの予定(free/busy のみ・メモを残せる)、自分で置いた予定(枠線だけ・長押しで移動)。右下の ＋ で記録
- タスク: 画面は 期限切れ / きょう の分だけ。メモ(既定)/ 期限までに / 習慣(毎日・毎週・続いた日数)/ やりたいこと / 完了 は「リスト」のタイルから 1 画面はさんで開く
- お金: 日ごと(他のタブと同じ上段・左上のカレンダー・v0.35: 日付の下の 1 行で足す(触れるとチップ)→ 支出 → 一覧・月の「日ごと」はその場で内訳)・2 タップ入力(金額 → カテゴリ)・予算・内訳・推移・ほしいもの・タイムラインの記録と紐づけ
- ふり返り(旧 日記): きょうはどうだった(レポートの見出しとタイル)→ 気持ちを残す(気分 / 元気+よかったこと・ひっかかったこと・明日は+メモ)→ AI(任意)→ 期限が近いタスク。あのころのきょう・続いた日数
- レポート(ふり返りの「レポートをすべて見る ›」/ ホームの円): 今日(判定の見出し・タイル・予定と実際・ふり返り)/ 7 日 / 30 日 / すべて(気分の推移を含む)
- 同期: 設定の先頭「いますぐ同期」(自動同期は開いたとき・戻ったとき・操作に乗せて)。「アップデートを確認」も同じ場所
- 作業用 BGM(任意・v0.32): 設定 › 作業用 BGM で有効にした人だけ、ホーム右上の ♪ をタップ → 好みに合う「まだ聞いていない」曲を 1 つ選んで YouTube(アプリかブラウザ)で開く。カタログは同じ作者の todaybgm から同梱(通信なし)・聞いた曲と 好き / ちがう は同期・既定は無効
- キャッチアップ(任意・v0.34): 設定 › キャッチアップ で有効にした人だけ、ホームの内訳の下の折りたたみに 研究(arXiv の Physical AI / デジタルツイン / BIM / インフラ管理)・建築DX・技術・ガジェット・趣味・料理 など複数のジャンルの新しい記事を数件ずつ(取得元は設定で ON / OFF)(気になる語を先頭・ジャンルを回す)。ホームは 2 列のカード(記事の代表画像・v0.36)。英語の題名は毎朝の更新で日本語に(v0.38: 既定は Google 翻訳の無料経路・登録不要・非公式。DeepL API Free の鍵を GitHub Secrets に `DEEPL_API_KEY` として登録すればそちら・Variables の `TRANSLATOR=none` で止める)。ホームでジャンルと気になる語(共通 / ジャンルごと・v0.39)で絞れ、☆ でブックマーク。取得元は設定の「＋ 取得元を足す」「取得元とジャンルの管理」から(GitHub のトークンを貼れば追加・削除を直接保存・無ければ JSON をコピーして GitHub で貼る)。開いた記事は消えず ✓(既読)に(v0.40)。取得元を非公開にしたいときは 設定の「自分のリポジトリに切り替える」で自分の private リポジトリに置ける(v0.41・取得元も記事も他の人には見えない)。公開のままだと取得元の一覧(data/feeds.json)と記事の一覧(data/feed.json)は公開リポジトリにある。タップでそのサイト(新しいタブ)。一覧は GitHub Actions が毎朝 `data/feeds.json`(取得元・リポジトリで編集)から `data/feed.json` に作り直す(無料・通信は同じサイトの 1 ファイルだけ)。開いた / 読まない の印は同期・既定は無効
- 天気と服装(任意・v0.29): 設定 › 天気と服装 で地域を登録した人だけ、ホームに地域ごとの 1 行(天気・気温・降水確率)と服装の一言。Open-Meteo(無料・キー不要)・接続先は 2 ドメインだけ・既定は無効

## 変えない約束(仕様書 §2)
5 タブ+設定・毎日の操作はワンタップ・主役は 1 つ・責めない・カレンダーは free/busy のみ・Drive は端末側暗号化(パスフレーズは sessionStorage)・提案はルールベース(アプリ内に AI は置かない)・外部依存は GIS のみ(例外: 任意の天気は Open-Meteo・既定は無効)。

## 技術
素の HTML/CSS/JS(ES2020+)・ビルド無し・npm 依存ゼロ。`js/` は役割別(main / store / time / log / plan / report / diary / money / ai / google / sync / passkey / ui / ui-*)。
純関数は `window.M` に載せ、`tests/index.html` で検証する。

## ローカルで試す
```
python -m http.server 8000
```
→ http://localhost:8000(file:// では Service Worker が動かない)

セルフテスト: http://localhost:8000/tests/ (localhost でのみ動く)。ネガティブコントロール 1 件を含むので「1 failed」が合格。

## 版の上げ方
`APP_VERSION`(js/main.js)・`news.json` の先頭(設定 › 更新履歴)・`sw.js` の CACHE 名を同じコミットで更新する。テストが 3 つの一致を確認する。

## iOS ショートカットから記録する
URL を開くだけで記録できる(iOS の「ショートカット」や「オートメーション」、ホーム画面のブックマークで使う):
- `https://zuno1000.github.io/merihari/?log=研究` … そのカテゴリの記録を開始(名前か id)
- `https://zuno1000.github.io/merihari/?log=stop` … 記録を終了
- `?kiai=1`(気合)は v0.28 で廃止(`js/features.js` の `KIAI` を true にすると戻る)

外部サイトのリンクから開いたとき(referrer が別のサイト)は無視する。

## Google 連携(任意)
設定 › Google から接続。カレンダーは freeBusy(空き/予定あり)だけを読み、書き込まない。Drive は appDataFolder に暗号化した 1 ファイル。
自分の Google Cloud プロジェクトの OAuth クライアント ID を使う場合は 設定 › Google の「クライアント ID」に入れる。
